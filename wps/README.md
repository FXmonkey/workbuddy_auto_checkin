# WPS 金山文档版（无需 GitHub）

不想碰 GitHub 的话，可以把整个自动化搬进**金山文档的智能表格**：脚本存在表格里，用 WPS 自带的定时任务每天触发，结果直接回写表格单元格，照旧推飞书卡片。逻辑与主仓库的 `wb_auto.py` 完全一致（先查再领、名额用完不重派、猫猫失败不影响签到结论）。

定时任务与 AirScript 脚本为免费功能（WPS 官方文档：进阶开发相关操作均不要求会员）。

## 准备

- 一个 WPS/金山文档账号
- `token`：在本机导出一次（这一步 WPS 替代不了，解密密钥绑在本机客户端里，约 28 天重复一次）。
  两种形式任选：
  - 没装 Python：下载仓库里的 **`refresh_token.exe`**，双击运行，复制 `----- 以下为 token -----`
    到 `----- 以上为 token -----` 之间那串字符（首次运行 SmartScreen 拦截时点「更多信息 → 仍要运行」）
  - 装了 Python：运行 `refresh_token.py`，同样复制标记之间的 token
- 飞书群机器人 webhook（可选，不填就只回写表格不推送）

## 配置步骤

1. 金山文档新建一张**智能表格**（入口：金山文档 → 新建 → 智能表格）。
2. 打开脚本编辑器：智能表格菜单里的 **脚本/效率 → 高级开发 → AirScript 脚本编辑器**（不同版本入口名称略有差异；如果在 WPS Office 客户端里打开，是「效率」页签 → 「高级开发」）。
3. 新建脚本，把 [`wb_auto_airscript.js`](wb_auto_airscript.js) 全文粘贴进去。要在【文档共享脚本】中，后面【定时任务】用。

![AirScript脚本](AirScript脚本.jpg)

4. 在编辑器工具栏的**「服务」里添加「网络 API」**——不加这个，脚本发不出任何请求。

![网络服务](网络服务.jpg)

5. 保存脚本，点一次「运行」做测试。脚本会自动创建名为 **签到自动化** 的工作表，里面有：

| 单元格 | 内容 |
| --- | --- |
| B1 | 粘贴 token（必填） |
| B2 | 粘贴飞书 webhook（选填） |
| B3 | 接口地址（留空即可，脚本会写默认值） |
| B5 / B6 / B7 / B8 / B9 | 运行后自动回写：签到结论 / 猫猫结论 / 整体 / 上次运行时间 / **飞书推送** |

![wps](wps.jpg)

6. 测试通过后，回到 **效率 → 高级开发 → 定时任务 → 新建任务**，选「每天」+ 时间，关联这个脚本。

![wps定时任务](wps定时任务.jpg)

之后每天自动执行；打开表格就能看到最近一次的结果，不用翻日志。

## 与 GitHub Actions 版的差异

| | GitHub Actions | 金山文档 AirScript |
| --- | --- | --- |
| 前置门槛 | Fork 仓库、配 Secrets | 建表格、粘脚本、填两个格子 |
| 触发 | cron（官方承认高峰期会丢任务） | WPS 定时任务 |
| 结果查看 | Actions 日志 / 飞书 | 表格单元格 / 飞书 |
| 凭据存放 | 加密的 Secret | 表格单元格明文（把文档权限设为仅自己可见） |
| token 更新 | 重跑本机脚本写入 Secret | 重跑本机脚本，把新 token 粘回 B1 |

## 已知边界

- token 在 B1 是明文，请把文档权限设为「仅自己可编辑/可见」。
- 认证被拒（卡片写「认证被拒」、B5 出现 ❌）= token 过期，重新导出并更新 B1。
- AirScript 网络请求只允许域名（不能带端口/IP），超时上限 60 秒——本脚本的请求都很小，碰不到。
- 表格读写层做了 1.0 / 2.0 双兼容（2.0 ET JSAPI：`Value` 是方法、`Value2` 可写、`Worksheets.Add` 四参；
  1.0 databook：`Value` 可写属性、`Sheets.Add` 五参、`Application.Enum`）。运行时自动探测，无需选版本。
- 表格显示签到成功、**飞书却没消息** — 看 B9「飞书推送」那行，失败原因直接写在里面：
  ① B2 没填（B9 写「未配置」）；② 地址复制不完整（飞书返回码 19001）；
  ③ 建机器人时开了**「签名校验」**——本脚本的推送不带签名，会被飞书拒绝，建机器人时选
  「自定义机器人」不要勾选签名校验，或关掉后重试。
- 若日志出现「无法创建工作表」，手动新建一个名为 **签到自动化** 的表再跑即可。
